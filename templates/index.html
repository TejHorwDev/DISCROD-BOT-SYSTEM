Your bots

Every bot you register here can post from this dashboard. Pick one in the header switcher (top right) to work as that bot, or override it per message in the preview panel.

ℹ️ Bots added here show as OFFLINE in your server - that is completely normal. This app uses Discord's REST API only, so a bot only "appears" for the moment a message is being posted. No gateway connection, no slash commands, no always-running loop.

How bots & tokens work here

  • Tokens live only in the .env file on your PC. They are never saved in data/bots.json, never sent to the browser (the dashboard only ever shows ••••last4), and never printed in logs.
  • Adding a bot is safe: the token is checked against Discord first; if it does not work, nothing is saved.
  • The invite link is generated automatically with exactly the permissions the app needs: View Channels, Send Messages, Embed Links, Attach Files, Read Message History. Mention Everyone is only included if you tick the box.
  • Disabling a bot keeps its record but skips it everywhere (sends, schedules, the switcher).
  • Removing a bot also deletes its token line from .env - except the very first DISCORD_TOKEN line, which is kept untouched for backward compatibility.
  • Each bot has its own rate limits - the app reads Discord's rate-limit headers per bot and waits exactly as long as Discord asks.
